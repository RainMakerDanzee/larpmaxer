# Bundled font licenses

All three families are licensed under the SIL Open Font License 1.1 (OFL), whose text is at
https://openfontlicense.org. The OFL permits bundling and redistribution with software.

| File | Family | Source |
|---|---|---|
| `manrope-var.woff2` | Manrope (Mikhail Sharanda / Google Fonts) | https://fonts.google.com/specimen/Manrope |
| `plex-mono-400.woff2`, `plex-mono-500.woff2` | IBM Plex Mono (IBM) | https://github.com/IBM/plex |
| `instrument-serif-italic.woff2` | Instrument Serif (Instrument) | https://fonts.google.com/specimen/Instrument+Serif |

No Reserved Font Names are used; these are the upstream OFL releases, subset to Latin.
