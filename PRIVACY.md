# Privacy

LarpMaxer has no server, no telemetry, and no account. It is a set of
instructions your own Claude Code session follows.

Your data — resume, profile, answers, application history — lives in plain
files in the folder you choose, on your machine. The agent sends job-ad text
and your profile facts to the model you are already signed into (Claude, under
Anthropic's [consumer privacy policy](https://www.anthropic.com/legal/privacy))
as part of doing the work you asked for, and to the job portals you tell it to
apply on. Nowhere else.

Credentials are never handled at all: when a portal needs a login, the agent
stops and you type it yourself in the browser.
